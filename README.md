# 🎵 Music Streaming Platform

Modern Spotify-inspired music streaming web application built using HTML, CSS, and JavaScript.

The platform provides an interactive music player experience with playlist management, audio controls, album covers, and responsive UI design.

---

## 🚀 Features

* 🎧 Interactive music player
* ▶️ Play / Pause controls
* ⏭️ Next & Previous track support
* 🔊 Volume control
* 📂 Playlist management
* 🖼️ Dynamic album/song covers
* 📱 Responsive modern UI
* ⚡ Smooth animations and transitions

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Audio API
